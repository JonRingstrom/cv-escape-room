INSTALL (Windows)
=================

This guide assumes you already have Python installed and use an editor
such as Visual Studio Code.

Type the commands one at a time and press Enter after each.
Wait for each one to finish before typing the next.


1. GET THE PROJECT
------------------
On the GitHub page, click  Code -> Download ZIP, and unzip it.
In Visual Studio Code: File -> Open Folder, and pick the project folder
(the one with requirements.txt in it).
Then open a terminal: Terminal -> New Terminal.


2. MAKE A VIRTUAL ENVIRONMENT
-----------------------------
A virtual environment is a private folder of Python packages for this
project only. It keeps these packages from clashing with anything else
on your computer, and you can delete it any time without harm.

    python -m venv venv

    venv\Scripts\activate

If the terminal says "running scripts is disabled", run this once and then run the activate command again:

    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

You now see (venv) at the start of the line, for example:

    (venv) PS C:\Users\<you>\Desktop\cv-escape-room>

Run  venv\Scripts\activate  again every time you open a new terminal.


3. INSTALL THE PACKAGES
-----------------------
    python -m pip install --upgrade pip

    python -m pip install -r requirements.txt

This one takes a few minutes. Then replace the OpenCV that EasyOCR
installs, because that version cannot open windows:

    python -m pip uninstall -y opencv-python opencv-python-headless

    python -m pip install opencv-python


4. DOWNLOAD THE MODELS
----------------------
YOLO26 and EasyOCR:

    python -c "import numpy as np; from ultralytics import YOLO; YOLO('yolo26n.pt')(np.zeros((640, 640, 3), np.uint8))[0].plot(); import easyocr; easyocr.Reader(['en'])"

MediaPipe:

    curl.exe -L -o pose_landmarker_lite.task https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/latest/pose_landmarker_lite.task

    curl.exe -L -o gesture_recognizer.task https://storage.googleapis.com/mediapipe-models/gesture_recognizer/gesture_recognizer/float16/latest/gesture_recognizer.task


NOTE: If Windows says "An Application Control policy has blocked this file",
see the last section of this guide.

5. CHECK THAT IT WORKS
----------------------
    python -c "import cv2, mediapipe, easyocr, ultralytics; print('All good!')"

    python 02_opencv_webcam.py

Your webcam should appear. Press q to close it.


6. DONE
-------
Everything is downloaded. From now on all the examples and puzzles
also run without internet. Always run them from this project folder.


IF WINDOWS BLOCKS A FILE
------------------------
If you see "An Application Control policy has blocked this file", Windows
Smart App Control is blocking files it does not recognise, such as pip.exe
or the PyTorch files that YOLO26 and EasyOCR need.

Turn it off (or on and off if it looks like it is not turned on):
  Windows Security -> App & browser control -> Smart App Control settings -> Off

Then run the command again. You can turn it back on after the hackathon.
